# 3 Offene Vorstandsentscheidungen

Diese Punkte sind **nicht** entschieden. Die App erfindet dafür keine Werte. Jeder Punkt ist im Adminbereich unter **Offene Entscheide** sichtbar. Dort sind auch Status und Datum der Entscheidung sowie eine Notiz hinterlegt. Spalte «Quelle»: AD = Anforderungsdokument 8.11.2026, PA = Projektauftrag, IMP = Befund aus dem Kartenimport.

Die Spalte «Bis zur Entscheidung» beschreibt, was der Prototyp bis dahin tut.
